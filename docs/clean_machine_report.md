# AIHR на чистом клоне

13 ноября 2026 года. Проверен `main` на коммите `40370c4` на Windows 10 (сборка 19045).
Docker Engine 27.4.0, Compose 2.31.0, Linux-контейнерам доступно 7,44 ГиБ памяти.

## Быстрый старт

1. Первый барьер — SSH. При обращении по адресу из README Git вернул `Host key verification failed.`
   Публичный репозиторий клонируется по HTTPS. Нужен параметр `--branch main`, поскольку GitHub
   выбирает другую ветку по умолчанию.
2. `docker compose build --no-cache` не дошёл до сборки приложения в текущем окружении.
   Повторная сборка без кэша из архива того же коммита с выключенным BuildKit завершилась
   на разборе Dockerfile примерно за секунду:

   ```text
   failed to parse Dockerfile: Syntax error - can't find = in "\\n". Must be of the form: name=value
   ```

   В инструкции `ENV HF_HUB_OFFLINE` записаны буквальные `\n`. Нужны обычные переносы
   строк с продолжением через `\` либо одна строка `ENV`. Это блокирует запуск по README
   при любом значении `WITH_EMBEDDINGS`.
3. На машине порт 8000 был занят локальным контейнером AIHR. После исправления Dockerfile
   на такой машине нужно задать свободный `API_PORT` или остановить свой старый контейнер.
   `scripts/clean_check.sh` использует фиксированные порты 8000 и 8501, поэтому для его
   сквозного прогона оба порта должны быть свободны.

Время успешной чистой сборки и размер нового образа пока не измерены. Скрипт
`scripts/clean_check.sh` не прошёл бы этап сборки на этом коммите по той же причине.

## Повторная проверка на `t/docker-demo`

- Исправлены переносы в Dockerfile. На том же Docker Engine сборка API прошла разбор Dockerfile и дошла до `uv sync`, сборка React — до `npm ci`.
- `docker compose config --quiet` прошёл. Из чистого клона отдельно прошли три теста React и сборка Vite с адресом API `/api`.
- Сквозной запуск Docker Desktop на этой машине не подтверждён: установка зависимостей в контейнерах зависла; отдельный тестовый контейнер Node остался в состоянии `Created`. Проверку из свежего клона также запускает GitHub Actions.

## Запуск без Docker

- Python 3.12.14, зависимости проекта установлены в отдельный каталог. Из чистого клона
  запущены FastAPI на порту 8001 и Streamlit на 8502.
- `/health` и `/_stcore/health` ответили HTTP 200. FastAPI сообщил `llm=none` и `retrieval=bm25`.
- `aihr demo` завершил все три сценария за 27,08 с. Битый DOCX вернул `E_CORRUPTED`,
  две остальные вакансии попали в рейтинг.
- Через Streamlit AppTest и живой API проверены кнопки «Пример из кейса» и «Пакет из кейса».
  Одиночный прогон показал рейтинг, пакетный — матрицу из четырёх резюме и трёх вакансий.
  При параллельных тестах первые попытки упёрлись в таймаут проверки. Повтор с большим
  таймаутом AppTest прошёл. В браузере сквозной прогон за отведённое время не завершился.
- LLM отключена, загрузка моделей запрещена переменными `HF_HUB_OFFLINE` и
  `TRANSFORMERS_OFFLINE`. Полное отключение сетевого интерфейса в этом прогоне не проверялось.
