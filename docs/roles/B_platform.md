## Главное правило

**Сначала всё работает от начала до конца на заглушках, потом заглушки заменяются настоящими модулями.** К вехе M0 `docker compose up` поднимает API и UI, загрузка файлов возвращает `MatchResult`, который проходит валидацию по контрактам. Дальше любой модуль можно заменить, не ломая остальное.

## Что значит «готово» для твоих задач

- `make test` зелёный, новые функции покрыты тестами.
- `make up` в чистом клоне собирается и запускается без ручных правок.
- Ошибки пользователю показываются по-русски: код, что случилось, что сделать. Без трассировок стека.
- В логах нет ПДн.
- Изменения в `docker-compose.yml`, `.env.example`, `Makefile` сразу отражены в README.
