# Статус задач

Обновляет Claude Code после каждой задачи: статус, дата, что сделано, что отложено и почему. Порядок — как в «Порядке в соло-режиме» из `README.md`.

Статусы: не начата · в работе · готова · готова частично (что осталось — в заметке) · отложена.

Режим вдвоём (D27): в заметке указываем, кто делает — A (тиммейт) или B (владелец). Порядок строк — исходный соло-порядок, распределение — в `README.md`.
