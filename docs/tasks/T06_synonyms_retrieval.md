# T06. Синонимы и поиск доказательств

**Владельцы:** A — синонимы; B — поиск · **Зависит от:** T01 · **Критерии:** 2 (6 баллов: синонимы, контекст)

## Цель

Требование и резюме говорят об одном разными словами: «JS» и «JavaScript», «ОС» и «основные средства», «1С» и «1С:Бухгалтерия». Без этого слоя всё поломается, команда отметила его как обязательный.

Синонимы работают в три слоя (D14):

1. **Словарь** нормализует написания и сокращения.
2. **Эмбеддинги** ловят смысловую близость.
3. **Суждение LLM** в проходах A и B решает окончательно.

## Часть A: синонимы

### 1. Словарь `data/synonyms.yaml`

```yaml
javascript:
  aliases: [js, джаваскрипт, яваскрипт, ecmascript, es6]
  class: programming_language
fixed_assets:
  aliases: [основные средства, ос, внеоборотные активы]
  class: accounting_object
react:
  aliases: [reactjs, react.js, реакт]
  class: frontend_framework   # vue и angular — тот же класс, но НЕ синонимы
```

Пример выше — только иллюстрация формата. Сам словарь собираем по общему списку областей, а не по вакансиям кейса.

Правила наполнения:

- Только точные синонимы, сокращения, транслитерации, частые опечатки. Смежные навыки («React» и «Vue») — **не** синонимы, это класс `adjacent`, он работает через поле `class`.
- Словарь общий, а не под три вакансии кейса (D12): ИТ, финансы и учёт, образование, офисные инструменты, языки, общие деловые навыки. 200–400 записей.
- Первую версию генерируем LLM по списку областей, затем просматриваем глазами. Мусор и спорные пары удаляем.

### 2. Расширение для незнакомых терминов

Термин из вакансии не найден в словаре → вызов LLM `aliases`: «перечисли написания, сокращения и английский вариант этого термина». Результат кэшируется (T03) и добавляется в словарь только в памяти прогона, в файл не пишется. Так слой работает на вакансиях любых профессий.

### 3. API

```python
canonicalize(term: str) -> str | None       # "JS" → "javascript"; неизвестное → None
aliases(canonical: str) -> list[str]
skill_class(canonical: str) -> str | None   # для смежных навыков
normalize_text(text: str) -> str            # заменяет алиасы на канонические токены, для BM25
```

Сравнение без учёта регистра, ё = е, знаки препинания внутри термина нормализуются (`1с` = `1С`, `c#` ≠ `c`).

### 4. Тесты

Таблица пар «написание → канон». Отрицательные пары: «Java» ≠ «JavaScript», «C» ≠ «C#», «ОС» в контексте «операционная система» — проверить, что словарь не склеивает разные смыслы. Для омонимов допускается `None` и решение на уровне LLM.

## Часть B: поиск доказательств

### 5. `retrieve/`

```python
class Retriever:
    def __init__(self, doc: Document): ...
    def search(self, query: str, terms: list[str], k: int = 8,
               section_roles: list[str] | None = None) -> list[tuple[str, float]]
```

- **BM25** (rank-bm25) по `normalize_text(masked_text)` фрагментов, токенизация: нижний регистр, стемминг snowball ru + en. Ловит точные термины: «1С», «МСФО», «ISO 9001».
- **Эмбеддинги** (sentence-transformers, CPU, модель из `EMBEDDINGS_MODEL`). Векторы фрагментов считаются один раз на документ и кэшируются по хэшу. Для моделей семейства e5 — префиксы `query:` и `passage:`. Пустой `EMBEDDINGS_MODEL` → только BM25.
- **Слияние** результатов через Reciprocal Rank Fusion (k = 60).
- **Фильтр по разделам:** для требования типа `education` ищем в `education`, для `skill` — в `skills` и `experience`, и т. д. Если в разделах ничего не нашлось, ищем по всему документу.
- Запрос = текст требования + `terms` (канонические термины и их алиасы).

### 6. Тесты

- На синтетическом резюме: «JS» находится по требованию «JavaScript» (BM25 через словарь); «вёл учёт имущества организации» находится по запросу про учёт имущества (эмбеддинги).
- Без эмбеддингов поиск работает и возвращает результаты.

## Критерии готовности

- [ ] Полнота поиска: на золотом наборе (T10) правильный фрагмент-доказательство попадает в топ-8 для ≥ 90% требований, где он есть. Меряет A.
- [ ] Время построения индекса резюме < 2 с на CPU.
- [ ] Решение по модели эмбеддингов записано в `docs/decisions.md` с замерами: время сборки образа, размер образа, полнота поиска.
