# T05. Профиль кандидата, даты, стаж

**Владельцы:** A — извлечение профиля; B — даты, стаж, уровни · **Зависит от:** T00, T01 · **Критерии:** 1 (8 баллов: опыт, навыки, образование, другие факты), 2 (длительность опыта, уровень задач)

## Цель

Из резюме получить структурированный профиль, где у каждого факта есть ссылка на фрагменты. Даты, стаж и уровни считает код. Профиль показывается в UI отдельным блоком: это и баллы критерия 1, и удобный рассказ про архитектуру.

Все пункты этой задачи команда отметила как обязательные.

## Часть A: извлечение профиля

### 1. Профиль по схеме

`extract_profile(resume, llm) -> CandidateProfile`, схема в `docs/contracts.md`:

- места работы: должность, организация, даты как написаны (`raw_dates`), задачи, достижения, инструменты, уровень задач, масштаб;
- образование: уровень, вуз, специальность, год окончания;
- навыки, языки, курсы и сертификаты, прочее (публикации, награды, волонтёрство).

У каждого элемента обязательные `fragment_ids`. Модель не считает даты и длительности: только переписывает `raw_dates` как есть.

### 2. Уровень задач по каждому месту работы

Модель выбирает уровень по рубрике и пишет масштаб, если он есть в тексте:

| Уровень | Признаки |
|---|---|
| `executor` | помогал, участвовал, выполнял поручения, под руководством |
| `independent` | вёл, отвечал за, самостоятельно, внедрил, настроил |
| `lead` | руководил, управлял командой из N, наставник, отвечал за направление |

Масштаб — только если он прямо написан: «команда 5 человек», «склад 2000 м²», «бригада из 8 человек». Не написан → `null`, не придумываем.

### 3. Тип упоминания навыка

`listed_only` — навык только в списке навыков. `evidenced` — навык встречается в описании опыта или проекта. Сначала решает код: каноническая форма навыка (T06-A) найдена во фрагментах какого-нибудь места работы → `evidenced`. Модель уточняет только неочевидные случаи. Навык без подтверждения — повод для вопроса кандидату (T09).

### 4. Промпт

`src/aihr/extract/prompts/profile.md`. Вход: фрагменты резюме `[R12] текст` с ролями разделов, только `masked_text`. Примеры из других профессий (D12). Явно сказано: если чего-то нет — пустой список или `null`, не придумывать.

### 5. Постобработка

Все `fragment_ids` существуют. Факты без валидных фрагментов отбрасываются с предупреждением. Навыкам проставляется `canonical` через `canonicalize()`.

## Часть B: даты, стаж, уровни (код, без LLM)

### 6. `normalize/dates.py` — разбор дат

| Вход | Результат |
|---|---|
| `03.2021`, `3/2021`, `2021-03` | `YearMonth(2021, 3)` |
| `март 2021`, `мар. 2021`, `March 2021`, `Mar 2021` | `YearMonth(2021, 3)` |
| `2021` | `YearMonth(2021, None)`, приближённо |
| `по н.в.`, `по настоящее время`, `н.в.`, `сейчас`, `present`, `current`, `до сих пор` | конец = `TODAY`, `is_current=True` |
| `2019 — 2021`, `2019–2021`, `с 2019 по 2021`, `с 03.2019` | пара начало / конец |
| `5 лет 3 месяца` (готовая длительность у hh.ru) | используется для проверки, не вместо дат |

Год без месяца: начало = январь, конец = декабрь, флаг `dates_approximate=True`. В расчётах показываем «≈».

### 7. `normalize/tenure.py` — стаж

- `duration_months` для каждого места работы.
- `total_experience_months` — **объединение** периодов: пересекающиеся работы не складываются дважды.
- Стаж по навыку: объединение периодов мест работы, во фрагментах которых навык упомянут. Записывается в `SkillMention.years`, плюс `last_used_year`.
- Стаж по теме порога (`threshold.subject`, например «складская логистика»): объединение периодов мест работы, которые модель отнесла к теме. Отнесение — в T07, расчёт — здесь: `tenure_for(positions: list[Position]) -> (months, approximate)`.
- Перерывы между работами больше 6 месяцев → `gaps_months` (для рисков в T09, без оценок).
- «Сегодня» берётся из `TODAY`, если задано, иначе текущий месяц. Тесты всегда задают `TODAY`.

### 8. `normalize/levels.py` — уровни

- Образование: порядковая шкала `secondary < vocational < incomplete_higher < bachelor = specialist < master < phd < doctor`. «Высшее» в требовании = `bachelor` и выше. Курсы — не уровень.
- Язык: CEFR A1…C2. Словарь словесных уровней: «базовый / начальный / elementary» → A2, «технический / читаю документацию / intermediate» → B1, «разговорный / upper-intermediate» → B2, «свободный / fluent / advanced» → C1, «родной / native» → C2. Неизвестное значение → `null`, не угадываем.

### 9. `enrich_profile(profile, today)` — собирает шаги 6–8 и возвращает дополненный профиль.

## Тесты

- A: на 4 резюме кейса все места работы, образование и навыки найдены (сверка с ручной разметкой, T10). Уровень задач совпадает с разметкой ≥ 80%.
- B: таблица случаев разбора дат, включая «по н.в.» и только год. Пересекающиеся периоды: 2019–2021 и 2020–2022 дают 36 месяцев, а не 48. Стаж по навыку. Перерывы. Уровни языка и образования.

## Критерии готовности

- [ ] Профиль 4 резюме кейса виден в UI отдельным блоком: места работы с датами и стажем, образование, навыки с типом упоминания и годами.
- [ ] Все расчёты стажа сходятся с ручным подсчётом.
- [ ] Резюме без дат не ломает расчёт: стаж `null`, предупреждение, требования по стажу получат «Не указано».
