## Интерфейс (Streamlit)

Сценарий от входа до результата без терминала.

1. **Загрузка.** Одно резюме и несколько вакансий (файлы или вставка текста). Кнопка «Пример из кейса». Индикатор этапов: загрузка → обезличивание → извлечение → сопоставление → отчёт.
2. **Рейтинг вакансий.** Карточка на вакансию: балл, интервал («61–74»), метка цветом, «закрыто 5 из 6 обязательных», объяснение места. Кнопка «Как посчитано» — формула и веса.
3. **Вакансия подробно** (вкладки):
   - *Требования* — таблица со статусами цветом, must / nice, цитатами. Клик по строке → резюме справа с подсветкой фрагмента. Косвенные доказательства — с цепочкой вывода.
   - *Профиль кандидата* — места работы, стаж, образование, навыки с типом упоминания (критерий 1 виден отдельно).
   - *Требования вакансии* — извлечённый список с must / nice и обоснованием.
   - *Отчёт* — сильные стороны, сверх требований, пробелы, риски, вопросы, рекомендация, письмо (с кнопкой «Копировать»).
4. **«Что ушло наружу»** — журнал исходящих запросов прогона (T02).
5. **Ошибки** — карточка на каждый проблемный файл: код, что случилось, что сделать.
6. **Скачать** JSON результата. DOCX/PDF — если останется время.
