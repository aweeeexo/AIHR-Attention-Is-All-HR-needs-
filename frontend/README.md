# AIHR · Фронтенд

Из корня репозитория запустите `docker compose up --build` и откройте
<http://localhost:3000>. React обращается к API через прокси на том же адресе.
Без файла `.env` API работает в упрощённом режиме.

Для разработки вне Compose нужны Node.js 22.12+ и запущенный API AIHR.
API можно поднять отдельно командой `docker compose up --build api` или через uv:

```sh
uv sync --frozen
uv run poe serve
```

В другом терминале запустите интерфейс.

```sh
cd frontend
npm ci
npm run dev
```

Откройте [интерфейс](http://localhost:5173) и нажмите «Запустить пример». В режиме «Одно резюме» можно выбрать документ из кейса. В режиме «Пакет резюме» пример использует все документы кейса.

По умолчанию интерфейс обращается к `http://localhost:8000`. Чтобы указать другой адрес, скопируйте `.env.example` в `.env.local` и задайте `VITE_API_URL`. Если меняете адрес интерфейса, добавьте его в `CORS_ORIGINS` на стороне API.

```sh
npm test
npm run build
npm run preview
```

Что умеет интерфейс: загрузка файлов или пример из кейса (одно резюме или пакет), живой прогресс расчёта через асинхронные задачи API (`/jobs`), рейтинг вакансий, таблица требований с цитатами и подсветкой в резюме, качество вакансии (`/runs/{id}/vacancy-check`), «что если» — пересчёт балла по ответам кандидата (`/runs/{id}/whatif`), отчёт рекрутеру, DOCX, журнал внешних запросов.

Готовая сборка находится в `dist/`. При развёртывании по HTTPS используйте HTTPS и для API. Шрифты входят в сборку. Документы отправляются только в настроенный API.
