# AIHR · Фронтенд

Для запуска нужен Node.js 22.12+ и API AIHR. Без файла `.env` API работает в упрощённом режиме.

Из корня репозитория запустите API командой `docker compose up --build api`. Если сборка останавливается на строке `ENV HF_HUB_OFFLINE` в Dockerfile, запустите API локально через uv и Python 3.12.

```sh
uv sync --frozen
uv run poe serve
```

В другом терминале запустите интерфейс.

```sh
cd frontend
npm ci
npm run dev
```

Откройте [интерфейс](http://localhost:5173) и нажмите «Запустить пример». В режиме «Одно резюме» можно выбрать документ из кейса. В режиме «Пакет резюме» пример использует все документы кейса.

По умолчанию интерфейс обращается к `http://localhost:8000`. Чтобы указать другой адрес, скопируйте `.env.example` в `.env.local` и задайте `VITE_API_URL`. Если меняете адрес интерфейса, добавьте его в `CORS_ORIGINS` на стороне API.

```sh
npm test
npm run build
npm run preview
```

Готовая сборка находится в `dist/`. При развёртывании по HTTPS используйте HTTPS и для API. Шрифты входят в сборку. Документы отправляются только в настроенный API.
